# Empnefsí Live

Website for Empnefsí Live, a Greek live band based in Germany — built with TanStack Start, React and Tailwind CSS.

## Development

You need Node.js and npm.

```sh
git clone https://github.com/3ytasarim/griechische-live-band.git
cd griechische-live-band
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
